Set up AI

Maya can use Ollama on this computer or a hosted AI API for a public deployment. For local use, install Ollama, start it, then run this command in Terminal:

ollama pull llama3.2:3b

For hosted deployments, set OPENAI_API_KEY and OPENAI_BASE_URL in the server environment before launching Maya.
